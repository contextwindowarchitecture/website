What CWA does

Name the parts. Fit them to a budget. Write down why.

Four planes and eleven typed slots give every piece an owner. The assembler admits what the request needs, fits it in tier order, renders it in a profile's order, and emits a trace. Same inputs, same request, every time.

03 / 03 Next · The schema ↓
The schema

Four planes. Eleven slots. Any number of items.

A plane says why a piece of context exists. A slot is a typed collection inside a plane, with its own admission rules. An item is one governed object in a slot — a policy, a retrieved chunk, a tool observation. Newcomers learn the planes; implementers use the slots; the assembler moves the items.
