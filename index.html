Context isn't a prompt. It's an assembled request.

Every model call is built from pieces: instructions, what the app knows, what it looked up, the conversation, the question. In most systems the step that puts them together has no name.

What CWA does

Name the parts. Fit them to a budget. Write down why.

Four planes and eleven typed slots give every piece an owner. The assembler admits what the request needs, fits it in tier order, renders it in a profile's order, and emits a trace. Same inputs, same request, every time.
