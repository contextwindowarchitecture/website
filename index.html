Context assembler spec · draft

Decide what your model sees. Keep a record of why.

CWA is a specification, and four open-source assemblers implement it in Python, TypeScript, Go and Rust. You call one right before your model call. It picks which instructions, documents and turns fit the token budget, and records what it left out. It never calls the model.

A real app

The same help-center bot, before and after.

A small bot answers questions from a product's help articles. Without CWA it pastes what it found into the prompt. With CWA it freezes what each source proposed into a snapshot, and the assembler decides what is sent.

Where the snapshot is built: context.py →The whole app, at 119b5cc →

before.pybuild_request()
def build_request(conversation: Conversation) -> tuple[list[str], list[dict[str, str]]]:    _, instructions = corpus.front_matter(INSTRUCTIONS.read_text(encoding="utf-8"))    hits = corpus.retrieve(conversation.question, TOP_K)    articles = "\n\n".join(f"[{hit.node.node_id}] {hit.node.get_content()}" for hit in hits)    system = f"{instructions}\n\nHelp-center articles:\n\n{articles}"    messages = [{"role": turn.role, "content": turn.text} for turn in conversation.turns[-MAX_HISTORY_MESSAGES:]]    messages.append({"role": "user", "content": conversation.question})    return [system], messages

Paste the top five articles into the system prompt, keep the last six messages, send.

after.pybuild_request()
def build_request(conversation: Conversation) -> tuple[dict[str, Any], AssemblyResult]:    document = context.snapshot(conversation)  # freeze: what each producer proposed, the route's policy, the clock    return document, context.assemble(document)  # decide: admission, fitting, rendering; no I/O, no model call

Freeze what each source proposed, then let the assembler decide. It reads nothing but the snapshot.

You are the Fernway help assistant. Answer questions about Fernway, the team task tracker, using only the help-center articles you are given.

If the articles do not answer the question, say so and suggest contacting support@fernway.example. Do not guess plan limits, prices or settings.

03 / 04 Next · Measured ↓
Measured

Long chats lose facts. Protected state keeps them.

The viability benchmark gave one model, Qwen3.6-35B-A3B, conversations of up to 100 turns on an 8,192-token budget, and changed only how each request was built.

One model, one budget. The gain comes from the state your app keeps, which CWA protects from being cut, not from reordering history. When the model writes that state itself, CWA is level with truncation.
