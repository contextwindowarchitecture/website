Getting started

From a prompt to a payload with owners.

You already have a function that builds the model call. These six steps turn what it sends into typed items in named slots, frozen in a snapshot that a conformant assembler renders into a payload with a trace. Following them needs nothing installed; the assembler you hand the snapshot to is one of the implementations on the Assembler page. Example · steps 1 and 3

A prompt, split into slots

Two samples, a system prompt and the same kind of conversation as a JSON array of chat messages, each split into the slots step 1 asks for. They are here to see CWA in action, not to try out your own prompt. You can edit a sample to watch the split respond, and Reset brings it back. The message array has to stay a JSON array: when an edit breaks it, the panel names the error and proposes nothing until it parses again. Each piece gets a proposed slot, that slot's default authority, and the item fields still to fill in. Only text the application wrote is split by what it says: a user or assistant message, or a paragraph that starts "User:", "Customer:" or "Q:", keeps its speaker's slot however it is worded, because wording never earns authority. The proposals come from simple wording rules written for these samples. On a prompt of your own they would guess, and a guessed governance item would claim a trust it has not earned. A system or developer message that matches no wording goes to governance.instructions, and any other piece the rules cannot place is left unassigned. Each body stays whole, as assembly keeps it, so material a user pasted into their message is delimited inside that body, in a form the material cannot imitate (R-10).

"No owner" counts the tokens the rules could not assign to a slot, estimated as characters divided by four rather than counted by a published tokenizer. Every other item still needs a source, a source_version and a freshness before an assembler will admit it (R-2), a memory item an expires and a source naming its turn (R-9), and a knowledge item a relevance score (R-13). The example already sets governance items to trust: verified and marks the query, history, memory and evidence injection_risk: untrusted_content (R-10). Replacing every TODO is step 3, and it is the part no example can do for you.
