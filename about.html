About

A free specification, revised in the open.

Context Window Architecture is a specification for assembling every model call from typed slots. It is not a library, not a framework, and not a product. Anyone may implement it; nobody needs permission.

CWA is
A vocabulary: four planes, eleven slots, one item shape. Twenty-three numbered requirements an assembler can be tested against. A contract producers can build to without knowing the assembler. A trace format that makes assembly decisions comparable across implementations.
CWA is not
A prompt template or a recommended order. Placement is a profile you evaluate. A replacement for your agent framework. It fills the blank the framework leaves. A security boundary. Governance items instruct; the application enforces. A claim about how models behave. The evidence page cites what is measured and stops there.
Maintainers & revision process

How the spec changes.

The specification is maintained by its authors in the contextwindowarchitecture organisation on GitHub. Numbered requirements are authored once in contract/requirements.json. The Spec page, assembler status matrix, and SPEC.md requirement reference are generated from it. The Spec page supplies normative context; published schemas define JSON field shapes. Automated checks reject stale generated artifacts.

Requirement numbers are permanent. A withdrawn rule keeps its number and is marked withdrawn. New rules take the next number, whatever section they land in.
